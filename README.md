# 🎬 Netflix Content Analysis

An Exploratory Data Analysis (EDA) project focused on Netflix movies and TV shows using Python.  
This project uncovers insights about Netflix content trends, genres, ratings, release years, countries, and content distribution using data visualization and analytics.

---

## 📌 Project Overview

This project analyzes Netflix's dataset to discover valuable insights such as:

- Movies vs TV Shows distribution
- Content growth over the years
- Most popular genres
- Top contributing countries
- Ratings distribution
- Release year trends
- Duration analysis

The project uses Python libraries for data cleaning, preprocessing, visualization, and exploratory analysis.

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

---

## 📂 Dataset

Dataset used: `netflix_titles.csv`

The dataset contains:

- Title
- Type
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre

## 📈 Key Insights

- Netflix has more Movies than TV Shows.
- Content addition increased rapidly after 2015.
- United States contributes the most content.
- Drama and Comedy are dominant genres.
